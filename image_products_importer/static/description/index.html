What Makes It Smart

Real-world filenames are messy. Our importer handles them all — automatically.

🔤

Case-Insensitive Matching

Blue Chair.jpg, blue-chair.jpg, and Blue_Chair.JPG all match the product Blue Chair. Your team can use any casing — the importer figures it out.
📦

True Bulk Upload

Import hundreds or thousands of images in a single operation. No batching, no waiting, no manual work. Built to handle large catalogs without slowing down Odoo.
🛠

Easy Wizard UI

No technical knowledge required. Any team member can run a bulk import in minutes using the simple step-by-step wizard interface built directly into Odoo.
📷

3 Match Methods

Match images to products using Internal Reference (SKU), Barcode, or Product Name. Works with however your catalog is structured.
✅

Duplicate-Safe

Already imported that image? No problem. The importer detects duplicates and skips them automatically, keeping your catalog clean and consistent.
🚫

Error-Proof

Files that don’t match any product are silently skipped. No crashes, no broken imports, no manual cleanup required after the operation.

How It Works

Three steps. That’s it.

1

Open the Wizard

Navigate to the Bulk Image Importer from the Inventory or Products menu. No setup required — it’s ready to use out of the box.
2

Upload Your Images

Select your image files — name them after the product’s SKU, barcode, or product name. Mixed casing, dashes, and underscores all work fine.
3

Import & Done

Hit import. Every image is matched to the right product and set as its main image. Unmatched files are skipped silently. No errors, no fuss.
